# AI / Machine Learning & Agentic Systems Engineer Roadmap

## Key Responsibilities
AI Engineers design, fine-tune, deploy, and operationalize Generative AI, Large Language Models (LLMs), Agentic Architectures, and Retrieval-Augmented Generation (RAG) systems.

## Key Technical Skill Requirements
- **Frameworks**: LangChain, LangGraph, LlamaIndex, AutoGen, CrewAI.
- **Vector Databases**: FAISS, ChromaDB, Pinecone, Weaviate, Qdrant.
- **LLM APIs & Infrastructure**: OpenAI API, Anthropic Claude, Groq, Ollama, Hugging Face Transformers.
- **RAG Architecture**: Document chunking, Semantic Embeddings, Hybrid Search, Reciprocal Rank Fusion, Re-ranking (Cohere).
- **Agentic Patterns**: Reflection, Tool Usage, Planning, Multi-Agent Collaboration, Memory Management.
- **MLOps**: vLLM deployment, TensorRT-LLM, MLflow, LangSmith evaluation, Prompt engineering & evaluation metrics (BLEU, ROUGE, RAGAS).
