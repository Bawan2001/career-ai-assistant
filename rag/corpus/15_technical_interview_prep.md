# Technical Interview Preparation & Data Structures Roadmap

## Technical Interview Stages
1. **Initial Recruiter Screen**: High-level background check, project highlights, salary expectations.
2. **Technical Coding Assessment (LeetCode Style)**: Arrays, Strings, Hash Maps, Two Pointers, Sliding Window, Trees, Graphs, Dynamic Programming.
3. **System Design Interview**: Scalability, Load Balancing, Database Sharding, Caching, API Gateway design.
4. **Behavioral & Culture Fit**: STAR method responses demonstrating leadership, conflict resolution, and teamwork.
