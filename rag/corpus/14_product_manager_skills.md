# Technical Product Manager Skills & Execution Framework

## Key Responsibilities
Technical Product Managers define product strategy, prioritize feature roadmaps, bridge engineering with business stakeholders, and measure metric KPIs.

## Essential Skill Matrix
- **Product Strategy**: Roadmap creation (Jira, Productboard), PRD (Product Requirement Documents) writing, User Story creation.
- **Analytics & Metrics**: Data-driven decisions (Mixpanel, Google Analytics, PostHog), A/B testing, North Star Metric definition.
- **Technical Literacy**: Understanding API integrations, system architecture trade-offs, Agile/Scrum ceremonies.
