# Cybersecurity Analyst & Information Security Guidelines

## Key Responsibilities
Cybersecurity Analysts protect networks, endpoints, and applications from cyber threats, vulnerabilities, and unauthorized access.

## Technical Skills Matrix
- **Core Security**: SIEM tools (Splunk, QRadar), Network Security (Wireshark, Firewalls, VPNs), Intrusion Detection Systems (Snort, Suricata).
- **Vulnerability Management**: Nessus, Nmap, OWASP Top 10 web security compliance.
- **Incident Response**: Threat hunting, forensic analysis, NIST Cybersecurity Framework.
- **Certifications**: CompTIA Security+, CEH (Certified Ethical Hacker), CISSP.
