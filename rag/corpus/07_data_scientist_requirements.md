# Data Scientist Skill Requirements & Portfolio Guidelines

## Overview
Data Scientists extract actionable business intelligence, build statistical models, and deploy machine learning pipelines.

## Key Core Technical Skills
- **Programming & Libraries**: Python (Pandas, NumPy, SciPy, Scikit-learn, Statsmodels), R.
- **Machine Learning**: Supervised Learning (Regression, Classification, Random Forests, XGBoost), Unsupervised Learning (Clustering, PCA, K-Means), Deep Learning (PyTorch, TensorFlow).
- **Data Visualization**: Matplotlib, Seaborn, Plotly, Streamlit, Tableau.
- **SQL & Data Extraction**: Advanced SQL (Window Functions, CTEs, Aggregations), ETL processes.

## Data Science Resume Recommendations
- Emphasize business impact: "Developed a customer churn prediction XGBoost model achieving 91% accuracy, reducing monthly subscription cancellation rate by 14%."
- Highlight end-to-end model deployment rather than standalone Jupyter notebooks.
