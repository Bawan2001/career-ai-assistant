# Cloud Architect & AWS/Azure Competency Matrix

## Key Responsibilities
Cloud Architects design resilient, cost-effective, secure cloud infrastructure across public and hybrid cloud providers.

## Key Technical Skill Requirements
- **Cloud Providers**: AWS (Solutions Architect Professional / Associate), Azure, Google Cloud Platform (GCP).
- **Core Cloud Services**: Computing (EC2, Lambda, ECS, EKS), Networking (VPC, Route53, CloudFront), Storage (S3, EBS, EFS), Security (IAM, KMS).
- **Infrastructure as Code (IaC)**: Terraform, AWS CloudFormation, Pulumi.
- **Cost & Reliability**: AWS Well-Architected Framework, FinOps cost management, Auto-scaling, Multi-region high availability.
