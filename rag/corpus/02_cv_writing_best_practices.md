# Professional CV Writing Best Practices for Tech Graduates

## Professional Summary Section
A 3-4 line elevator pitch highlighting your core technical stack, key achievements, domain focus, and career objectives.
- **Good Example**: "Results-driven Software Engineer with 2+ years of experience building scalable backend microservices in Python, Django, and AWS. Proven track record of optimizing SQL query performance by 35% and delivering robust REST APIs for enterprise clients."

## Technical Skills Categorization
Group skills logically to improve readability:
- **Languages**: Python, Java, C++, TypeScript, SQL
- **Frameworks**: React, FastApi, Django, Spring Boot, Node.js
- **Cloud & DevOps**: AWS (EC2, S3, Lambda), Docker, Kubernetes, GitHub Actions, Terraform
- **Databases & Vector Stores**: PostgreSQL, MongoDB, Redis, FAISS, ChromaDB

## Project Section Strategy for Students & Graduates
For university students and job seekers lacking formal corporate experience, personal and academic projects demonstrate hands-on execution:
- Include 2–3 high-impact technical projects.
- Mention target domain, technical stack, architecture, live deployment links, and GitHub repository links.
- Emphasize complex concepts: Agentic AI workflows, RAG pipelines, Distributed database queries, Microservices architecture.
