# Data Engineer Skills & Big Data Architecture

## Key Focus
Data Engineers build reliable, scalable ingestion infrastructure, data lakes, and analytical processing pipelines.

## Skill Matrix
- **Data Warehousing & Lakes**: Snowflake, Databricks, Google BigQuery, AWS Redshift.
- **Orchestration**: Apache Airflow, Prefect, Dagster.
- **Big Data Processing**: Apache Spark (PySpark), Hadoop, Kafka streams.
- **Data Modeling**: Snowflake schema, Star schema, dbt (data build tool).
- **SQL & Cloud**: Advanced PostgreSQL, AWS S3, Athena, IAM policies.
