# UI/UX Designer Career Guidelines & Portfolio Standards

## Key Responsibilities
UI/UX Designers conduct user research, create wireframes, build interactive prototypes, and design polished user experience interfaces.

## Essential Skill Matrix
- **Design Tools**: Figma, Adobe XD, Sketch, Framer.
- **UX Research**: User personas, usability testing, journey mapping, information architecture.
- **Design Systems**: Component libraries, design tokens, responsive typography, WCAG accessibility standards (AA/AAA).
- **Design Portfolio**: 3 detailed case studies walking through problem statement, research findings, wireframes, prototype iterations, and user testing outcomes.
